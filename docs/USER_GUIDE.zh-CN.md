# Photo Way 使用指南

[English](USER_GUIDE.md) · [项目简介](../README.zh-CN.md)

## 安装

从项目发布页下载 Windows 安装程序（EXE 或 MSI），或 macOS 通用版 DMG，并按提示安装。v0.1.0 安装包未签名：Windows SmartScreen 如出现提示，可选择“更多信息”→“仍要运行”；macOS 首次启动时可按住 Control 键点按应用，再选择“打开”。macOS 上的完整操作流程尚未经过人工验证。

## 制作路线图

1. 将文件夹、照片或视频拖入应用。支持 JPEG、HEIC/HEIF、PNG、TIFF、DNG、MOV 和 MP4 等格式。
2. 查看导入摘要。没有可用位置信息或无法读取的文件会被跳过。
3. 选择媒体和隐私选项。“仅缩略图”可减小导出体积；网页尺寸或原始媒体会占用更多空间。移除 EXIF 和降低坐标精度可减少分享出去的信息。
4. 查看实时预览，再导出 HTML 文件、文件夹或 ZIP 包。分享文件夹或 ZIP 时，请保留其中的所有文件；直接从本地打开时，应先解压 ZIP，再打开 `index.html`。
5. 分享导出结果。接收者只需现代浏览器，无需安装 Photo Way。离线世界底图不需要网络；卫星、街道、地形及 3D 地形底图需要联网。

在导出的地图中，可以通过时间线和筛选器浏览行程。拖动图钉可修正位置，也可以隐藏项目；使用“保存副本”可将修改写入新的导出文件。自行填写的标题和文件名会保持原样。

## v0.2.0 的语言功能

以下双语功能正在开发中，v0.1.0 尚不支持。计划中的桌面应用“Language / 语言”设置提供“跟随系统”“English”和“简体中文”；独立的导出语言选项决定新导出地图的初始语言。接收者可以在地图中切换英语和简体中文；浏览器存储可用时，选择会按行程保存。切换语言不会翻译照片标题或文件名。已生成的 v0.1.0 地图保留原有界面；如需双语控件，请重新导出。系统文件选择器和第三方地图标注可能使用各自的语言设置。

安装程序的语言只影响安装界面，不会修改应用已保存的语言偏好。两个 Windows MSI 版本安装的是同一款双语应用；NSIS 安装程序提供语言选择器。
