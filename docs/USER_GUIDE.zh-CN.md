# Photo Way 使用指南

[English](USER_GUIDE.md) · [项目简介](../README.zh-CN.md)

## 安装

从[最新发布页](https://github.com/JohnnnyTang/photo-way/releases/latest)下载 Windows 安装程序（EXE 或 MSI），或 macOS 通用版 DMG，并按提示安装。可用发布页的 `SHA256SUMS.txt` 校验文件：Windows 运行 `certutil -hashfile <文件> SHA256`，macOS 运行 `shasum -a 256 <文件>`。

安装包目前未签名：Windows SmartScreen 如出现提示，可选择“更多信息”→“仍要运行”；macOS 首次启动时可按住 Control 键点按应用，再选择“打开”。如果新版 macOS 没有“打开”按钮，可先尝试启动一次，再到“系统设置”→“隐私与安全性”中选择“仍要打开”。

## 从手机取得含位置信息的原始文件

Photo Way 读取文件内已有的位置信息，无法补回分享或传输时被移除的位置。

- **iPhone → Mac：**在“照片”中选中文件，分享时打开顶部“选项”里的“所有照片数据”，再用隔空投送；也可在 Mac 的“照片”中选择“文件”→“导出”→“导出未修改的原片”。
- **iPhone → Windows：**通过数据线连接并信任电脑，再用 Windows“照片”导入，或从 `DCIM` 文件夹复制。通过聊天应用分享可能会移除位置。
- **Android：**通过 USB 文件传输复制 `DCIM/Camera` 最稳妥。Google 相册分享或下载有时会移除位置；Google Takeout 可能把位置放在单独的 JSON 文件中，Photo Way 目前不读取这种附属文件。
- 手机拍摄时也必须开启相机的位置记录。导入前可运行 `photoway inspect <文件夹>` 查看每个文件是否有位置，以及跳过原因。

## 制作路线图

1. 将文件夹、照片或视频拖入应用，也可点击 **Add photos...** 或 **Add folder...**。支持 JPEG、HEIC/HEIF、PNG、TIFF、DNG、MOV 和 MP4 等格式。
2. 查看导入摘要。没有可用位置信息或无法读取的文件会被跳过。
3. 选择媒体和隐私选项。“仅缩略图”可减小导出体积；网页尺寸或原始媒体会占用更多空间。移除 EXIF 和降低坐标精度可减少分享出去的信息。
4. 点击 **Build preview** 查看实时地图。若之后修改媒体选项，需重新生成预览。再点击 **Export...** 导出 HTML 文件、文件夹或 ZIP 包。分享文件夹或 ZIP 时，请保留其中的所有文件；直接从本地打开时，应先解压 ZIP，再打开 `index.html`。
5. 分享导出结果。接收者只需现代浏览器，无需安装 Photo Way。离线世界底图不需要网络；卫星、街道、地形及 3D 地形底图需要联网。

在导出的地图中，可以通过时间线和筛选器浏览行程。拖动图钉可修正位置，也可以隐藏项目；使用“保存副本”可将修改写入新的导出文件。自行填写的标题和文件名会保持原样。

### 导出选项

| 选项 | 用途 |
|---|---|
| 标题 | 显示在地图顶部，不会因切换界面语言而被翻译。 |
| 完整尺寸照片 | “仅缩略图”体积最小；“网页尺寸”添加长边 1280–4096 像素的照片；“原始文件”保留原件，体积最大。 |
| 包含视频 | 关闭后只保留视频或实况照片的静态预览。 |
| 移除 EXIF | 默认开启；选择原始文件时尤其重要。 |
| 坐标精度 | 可保留精确位置，或四舍五入到 6、5、4、3、2 位小数；2 位约为 1 公里，3 位约为 100 米。 |
| 默认底图、主题 | 决定接收者首次打开地图时的显示方式；接收者仍可自行切换。 |

单个 HTML 便于直接发送，并支持“保存副本”。照片较多、需要原始媒体或文件超过约 50 MB 时，优先选文件夹或 ZIP；应用会在导出前显示大小估算。ZIP 接收者需要先解压。

## 使用导出的地图

双击 HTML 文件或文件夹中的 `index.html` 即可打开，不需要安装应用或启动服务器。支持现代版 Chrome、Edge、Firefox 和 Safari，包括手机浏览器。

- 地图按行程顺序连接图钉，标出起点和终点；缩小时图钉会聚合，放大后可看到照片缩略图。点击图钉查看卡片，**Open** 可打开照片或视频。
- **Fit all** 显示整段行程；**Globe** 和 **Flat map** 切换地球仪和平面地图；播放按钮可按顺序浏览，速度可选 1× 至 8×。
- **Offline world** 底图可离线使用。卫星、街道、地形和 3D 地形底图需要联网；在线图块无法载入时会回退到离线底图。
- 主题有自动、浅色、深色、黄昏、纸张和森林。底部时间线可定位照片；按日期浏览时，日期依据拍摄地的当地时间分组。
- 日期列表显示距离、爬升、下降和用时。隐藏项目、调整位置或开关 GPS 异常点筛选后，统计会更新。海拔数据不足时不会显示爬升；小于 10 米的变化会被忽略。
- 筛选器可按照片、视频、实况照片过滤，显示或隐藏路线，排除疑似 GPS 异常点，并按时间着色、标记站点序号、在悬停时突出路线片段。

点击图钉后可拖动它修正位置，也可隐藏项目。修改按地图保存在当前浏览器；换浏览器、换电脑或清除浏览器数据后不会自动保留。**More** 菜单中的 **Export corrections** 可导出修正 JSON；**Save a copy** 可把编辑写入新的单文件 HTML，并可选择是否保留隐藏项目。文件夹和 ZIP 导出不支持“保存副本”。如果浏览器禁止存储，当前修改仍可操作，但刷新后可能丢失，请及时导出修正或保存副本。

## 分享与隐私

路线图会暴露照片拍摄地点。分享前检查住处、工作地点和学校附近的照片；可在导入前移除，或隐藏后用“保存副本”且不保留隐藏项目。降低坐标精度可模糊位置；除非确需原件，建议保持“移除 EXIF”开启，避免导出原始文件。单个 HTML 内仍包含缩略图和坐标，应像对待照片一样保管。

应用本身不会上传文件。使用在线底图时，地图服务商可能知道你浏览的区域；离线世界底图不发送地图请求。

## 命令行

发布页提供 `photoway` 命令行工具。命令及参数保持英文，机器可读的 JSON 字段与错误代码也不翻译。运行 `photoway --help` 或 `photoway <命令> --help` 可查看完整说明。

```sh
photoway inspect ~/Pictures/trip
photoway build ~/Pictures/trip -o trip.html --coord-decimals 3
photoway build ~/Pictures/trip -o trip.zip --format zip --full original
photoway serve trip.zip
```

`build` 的 `--format html|dir|zip` 选择格式，`--full none|web|original` 选择媒体大小；还可设置 `--title`、`--web-edge`、`--no-video`、`--keep-exif`、`--coord-decimals`、`--cache`、`--theme` 和 `--basemap`。`inspect --json` 输出可用文件与跳过原因。`serve` 默认使用 `127.0.0.1:8765`，可用 `--addr` 修改。

## 常见问题

- **找不到带位置的文件：**按上文重新取得原始文件，并用 `photoway inspect` 检查；相机拍摄时也可能未开启位置记录。
- **部分文件被跳过：**可能没有位置、文件损坏、格式不支持或重复导入。查看导入摘要中的原因。
- **视频无法播放：**HEVC 视频是否可播放取决于浏览器、系统和硬件。可换用 Safari 或 Edge，或将视频转为 H.264；地图仍可显示静态预览。
- **只能看到预览图：**导出时选择了“仅缩略图”；改选网页尺寸或原始文件后重新导出。
- **文件太大或打开缓慢：**改用文件夹或 ZIP，关闭视频，或降低网页尺寸。
- **地图空白或提示 WebGL 2：**更新浏览器或开启硬件加速；时间线仍可使用。
- **在线底图无法加载：**检查网络。离线世界底图无需联网。
- **ZIP 打开是空白页：**先解压，再打开 `index.html`。
- **编辑丢失：**编辑仅保存在作出修改的浏览器里；使用“导出修正”或“保存副本”保留。

## v0.2.0 的语言功能

桌面应用的“Language / 语言”设置提供“跟随系统”“English”和“简体中文”；独立的导出语言选项决定新导出地图的初始语言。接收者可以在地图中切换英语和简体中文；浏览器存储可用时，选择会按行程保存。切换语言不会翻译照片标题或文件名。已生成的 v0.1.x 地图保留原有界面；如需双语控件，请重新导出。系统文件选择器和第三方地图标注可能使用各自的语言设置。

安装程序的语言只影响安装界面，不会修改应用已保存的语言偏好。两个 Windows MSI 版本安装的是同一款双语应用；NSIS 安装程序提供语言选择器。
